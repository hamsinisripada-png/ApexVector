# ApexVector

AI-powered motorsport telemetry and race strategy platform built using React, TypeScript, TailwindCSS, and Supabase.

## Features

- Real-time telemetry dashboard
- AI-powered race strategy analysis
- Predictive analytics
- Driver performance tracking
- Session analytics
- Motorsport command center

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Supabase
- Vite
- Recharts

## Installation

```bash
npm install
npm run dev
